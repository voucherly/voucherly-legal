# Data Processing Agreement

Versione 1.1 del 24/08/2026

Elenco dei sub-responsabili del trattamento
================================================================================================

[Nomina a Responsabile del trattamento](/privacy/dpa)


Il titolare del trattamento autorizza il ricorso ai seguenti sub-responsabili del trattamento:

| Nome ed estremi di identificazione del Sub-responsabile | Dati | Descrizione del trattamento  |
| --- | --- | --- |
| Register | Dati anagrafici, dati di contatto, importi delle transazioni, log di sistema | Ospita l’infrastruttura per l'esecuzione del Servizio e il sistema di raccolta dei log |
| Hostinger (Francoforte, Germania) | Dati anagrafici, dati di contatto, importi delle transazioni, log di sistema | Ospita l’infrastruttura per l'esecuzione del Servizio |
| AWS (eu-central-1) | Dati anagrafici, dati di contatto, importi delle transazioni, log di sistema | Ospita il backup degli archivi e gli oggetti (immagini, esportazioni e file) caricati e/o usati tramite il Servizio |
| Brevo (EU) | Dati anagrafici, dati di contatto (e-mail) | Recapita i messaggi di posta elettronica previsti dal Servizio |
| GatewayAPI (EU) | Dati di contatto (numero di telefono) | Recapita i messaggi SMS previsti dal Servizio |
| Sentry (EU) | Identificativi utente o riferimenti interni all’applicazione | Sistema di monitoring e gestione errori ai fini di diagnostica |
| PostHog (EU) | Identificativi utente o riferimenti interni all’applicazione | Raccoglie eventi e log applicativi ai fini di diagnostica e di analisi statistica sull’utilizzo del Servizio |
